# Authentication Audit

## Scope and evidence

Read-only audit of the supplied `Dolphin-air-CRM-main (10).zip`, cross-checked against Stage 2 migration documents and the extracted source. The ZIP remains unmodified. Stage 2 maps are useful indexes, not verification evidence. Legacy evidence includes `src/App.tsx`, `src/views/LoginView.tsx`, `src/lib/auth.ts`, `server.ts`, Firestore rules, staff/customer auth helpers, and the visa/supplier/notification permission helpers.

## Security finding

Legacy bearer token formats are not suitable as authenticated credentials. New work removes that trust path. Password migration and live customer OTP remain blocked until isolated credentials/provider configuration and compatible data handling are approved. No production identity provider was contacted.
