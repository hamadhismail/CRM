# Technology Stack

- CRM: React, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, Zustand.
- Portal: Next.js, TypeScript, Tailwind CSS.
- API: NestJS, TypeScript, REST/OpenAPI foundation, PostgreSQL/Prisma placeholder.

- Monorepo: pnpm workspaces and Turborepo.

Dependencies are declared but not installed in Stage 1.
